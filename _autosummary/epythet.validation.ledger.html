epythet.validation.ledger¶

The artifact ledger: rule definitions (bundled YAML) and observations (user data dir).

Storage is split by mutability, as decided in the v2 decision record (D8):

  • Rules are one YAML file per rule under epythet/ledger/rules/<group>/ (the build namespace lives in build_warnings/: a directory named build/ is dropped from wheels by the project’s .gitignore) with a sibling .py fixture that doubles as the regression test. They are human-edited, rarely, and ship inside epythet.

  • Observations (occurrences with file paths and snippets from real repos) are append-only JSONL under the user data dir, never inside the repo, because they are derived from repositories that are not all public. Occurrence counts are a derived view over that file, computed on read.

The ledger= seam of epythet.validation.validate() accepts None (bundled rules), a directory (bundled rules plus a package-local overlay, same id overrides) or a ready Ledger.
